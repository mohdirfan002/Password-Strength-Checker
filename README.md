# Password Strength Checker

## Overview
A Python-based cybersecurity tool that analyzes password strength using multiple security checks.

---

## Features
- Password strength scoring
- Uppercase/lowercase checks
- Number validation
- Special character detection
- Common password detection
- Sequential pattern detection
- Security recommendations
- Report generation

---

## Technologies Used
- Python
- Regex
- Colorama
